カエルパス

よくある質問

はじめに

パスワードは定期的に変えないといけないのですか？

いいえ、一律に変える必要はありません。大切なのは、使い回さないことと、長くすることです。定期的な変更を一律に求めない考え方は、米国の NIST のガイドラインなどでも示されています。 カエルパスの「見直し」は、変えるきっかけを用意するためのものです。漏洩のニュースがあったとき、長く変えていないとき、短いパスワードを使っているときなどに、落ち着いて変えられるよう手伝います。間隔はサービスごとに選べます（プレミアム）。

データはどこに保存されますか？

お使いの端末の中だけです。端末の中で暗号化して保存し、インターネットには送りません。運営者もデータを見ることはできません。

無料プランとプレミアムの違いは？

無料プランは5件まで、見直しの間隔は3ヶ月です。プレミアムは件数の制限がなく、間隔をサービスごとに1〜12ヶ月で選べます。

ロック・パスコード

パスコードを忘れました

パスコードは端末の中だけで確かめているため、運営者にも戻せません。バックアップがあれば、アプリを入れ直してからバックアップを読み込むと戻せます（バックアップ用パスワードが必要です）。 何度か間違えると、少し待ち時間が出ますが、データが消えることはありません。

Face ID が使えなくなりました

端末に顔や指紋を新しく登録すると、安全のため Face ID での解除が使えなくなります。パスコードで開いてから、設定で Face ID をもう一度オンにしてください。

機種変更・バックアップ

機種変更のときは？

  1. 古い端末で「バックアップ」→ バックアップ用パスワードを決めて書き出し、ファイルアプリなどに保存
  2. 新しい端末でカエルパスを入れ、パスコードを決める
  3. 「バックアップ」→「バックアップから戻す」でファイルを選び、バックアップ用パスワードを入れる iPhone と Android の間でも同じ手順で移せます。

バックアップ用パスワードを忘れました

バックアップ用パスワードはどこにも保存していないため、そのバックアップは開けません。古い端末が使えるうちに、新しいバックアップを作り直してください。

お知らせ

お知らせが届きません

  • 端末の設定で、カエルパスの通知が許可されているか確かめてください
  • アプリの設定で「お知らせを受け取る」がオンか確かめてください
  • 集中モードやおやすみモードの間は、届かないことがあります
  • アプリを一度開くと、お知らせの予定を作り直します

通知にサービス名を出したくない

設定の「サービス名を出さない」をオンにすると、「見直しの時期のサービスが◯件あります」とだけ表示します。

プレミアム

解約するには？

端末の設定から行います。 - iPhone：設定 → [自分の名前] → サブスクリプション → カエルパス - Android：Google Play → プロフィール → お支払いと定期購入 → 定期購入 → カエルパス アプリを削除しても解約にはなりません。

解約したらデータはどうなりますか？

登録したデータはそのまま使えます。新しい追加（6件目以降）と、見直しの間隔の変更ができなくなります。

機種変更したらプレミアムが外れました

カエルパスの設定 → 「購入を復元する」を押してください。同じ Apple ID または Google アカウントで購入していれば戻ります。

その他

変更ページが開けません

サービス側でアドレスが変わった可能性があります。サービスの公式サイトで変更ページを探し、カエルパスで「編集」してアドレスを直してください。

不具合の報告・要望

お問い合わせフォーム（https://forms.gle/4QYCF3ZrTaQTNMqf8）から送ってください。返信はメールで行います。パスワードや ID など、カエルパスに保存している情報は書かないでください。
